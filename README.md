# ⚡ EduConsultPro — Salesforce CRM for Academic Institutions

EduConsultPro is a comprehensive Salesforce CRM customization designed to streamline academic operations, student onboarding, lead nurturing, and program coordination. Built using native Salesforce capabilities (Apex, Lightning Web Components, Flows, and Security Controls), the CRM optimizes institutional workflows from prospective lead to student graduation.

## 🌟 Key Functional Domains

### 1. 🎯 Student Lead Nurturing & Onboarding
*   Configured Custom Objects and standard Salesforce Leads for student applicants.
*   Designed automated **Salesforce Flows** to transition leads from Prospect -> Application -> Enrollment.
*   Established lead assignment rules to route inquiries to specific academic counselors.

### 2. 🏛️ Academic Course & Session Management
*   Designed relationship models between Custom Objects (Courses, Batches, Instructors, and Enrollments).
*   Created Apex Triggers to prevent schedule conflicts and validate enrollment caps.

### 3. 🖥️ Lightning Web Components (LWC)
*   Developed a custom student dashboard LWC showcasing current course progress, batch announcements, and counselor contacts.
*   Created Apex-backed LWC search tools for counselors to query course catalogs dynamically.

### 4. 🔒 Role Hierarchy & Security Configuration
*   Configured Object-Level Security (Profiles/Permission Sets) to separate permissions between Admissions, Instructors, and Students.
*   Established Org-Wide Defaults (OWD), Roles, and Sharing Rules to ensure student records are visible only to assigned counselors.

### 5. 📊 Reporting & Analytics
*   Built real-time Executive Dashboards displaying Lead Conversion Rate, Course Enrollment Trends, and Counselor Case Resolution Times.
